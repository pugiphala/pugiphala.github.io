# Pūgīphala website

A responsive, single-page static website concept for a technology-led arecanut venture. Built with plain HTML, CSS and JavaScript; no build tools or paid hosting are required.

## Preview locally

Open `index.html` in a modern browser. An internet connection is needed for the Google Fonts and remote Unsplash photography used in this first version.

## Before publishing

1. The enquiry recipient is already configured as `Hellopugiphala@gmail.com`.
2. Review the brand spelling, Kannada text, service descriptions and business claims.
3. Replace the sample Unsplash photographs with your own plantation and product photographs when available.
4. Add your verified phone number, WhatsApp link, business address and social media links when ready. These have intentionally not been invented.

## Publish free with GitHub Pages

1. Create a GitHub repository, for example `pugiphala-website`.
2. Upload `index.html`, `styles.css`, `script.js` and this README to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. Wait for GitHub Pages to publish the site. Your free URL will be `https://YOUR-USERNAME.github.io/pugiphala-website/` (replace `YOUR-USERNAME` with your GitHub username).

A custom domain is optional and would have a separate registration cost. Keep the free GitHub Pages address for now.

## Important

This is a front-end website. The enquiry form opens the visitor's email application; it does not store submissions in a database. For a hosted form, connect a form provider or a backend before launch. The current content is proposed brand copy, not a representation of services already delivered or certifications held.
